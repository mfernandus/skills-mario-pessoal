# skills-mario-pessoal

Skills pessoais de Mário Fernando e as skills de apoio (Anthropic e terceiros) que conversam com as skills da Next Editorial. As skills da Next ficam separadas, no repositório [skills_nexteditorial](https://github.com/mfernandus/skills_nexteditorial).

## Estrutura

- `pessoais/` — skills de uso pessoal (nx-mac-clean).
- `anthropic/documentos-e-planilhas/` — docx, pdf, xlsx e pptx.
- `anthropic/visual/` — canvas-design e theme-factory.
- `anthropic/criacao-de-skills/` — skill-creator.
- `terceiros/` — karpathy-guidelines.
- `MAPA-DE-CONEXOES.md` — quais skills de apoio servem a quais skills da Next e pessoais, nos dois sentidos.
- Cada skill de apoio traz um `CONEXOES.md` com as ligações dela.
